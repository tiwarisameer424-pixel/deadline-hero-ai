# Deadline Hero AI 🏆

> An AI productivity companion that helps you **finish** tasks, not just remember them.

## Problem
Students, professionals, and entrepreneurs miss deadlines, assignments, and
commitments because traditional tools only send passive reminders that are
easy to ignore. They don't help you actually take action.

## Solution
Deadline Hero AI is an **agentic** productivity coach that follows a
Perceive → Plan → Act → Adapt loop. It breaks big tasks into a timed plan,
explains its reasoning, proactively detects deadline risk, and — uniquely —
**negotiates by voice** when you push back, adapting the plan instead of
forcing you.

## Key Features
- 🧠 AI Task Breakdown — one big task → timed sub-steps
- ⚡ Autonomous Plan + Priority with visible reasoning ("why")
- 🎙️ Negotiate-With-AI by voice — the AI adapts when you push back
- 🚨 Proactive Deadline Risk Detector — warns and re-plans before you fall behind
- 📊 Daily Summary / Focus Report with a Productivity Score
- 🎯 Focus Mode — one task at a time

## Tech Stack
- Google AI Studio (build environment)
- Gemini 2.5 Flash (reasoning, planning, negotiation)
- React + Node/Express
- Web Speech API (voice input & output)
- Google Stitch (UI/UX design)
- Deployed on Google Cloud Run
